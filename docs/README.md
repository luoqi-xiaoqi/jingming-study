# 🌻 靖铭学习工作台

## 项目简介
一款专为靖铭小朋友（小学一年级）打造的学习工作台，采用植物大战僵尸游戏主题，浅蓝色+白色配色风格，融合了汉字学习、古诗背诵、数学练习、拼音学习、错题本、保卫基地游戏、奖励中心、打卡日历、健身饮食、英语拓展、计划备忘录等11大功能模块。

## 启动方式

### 方式一：直接打开
直接双击 `index.html` 即可在浏览器中打开。

### 方式二：本地服务器
```bash
# 进入项目目录
cd /workspace

# 使用 Python 启动
python3 -m http.server 8090

# 浏览器访问
http://localhost:8090/index.html
```

### 方式三：使用 Node.js
```bash
# 安装简易服务器
npm install -g http-server

# 启动
http-server -p 8090
```

## 功能模块详解

### 1. 汉字学习 📝
- **每日学习 25 个字**，目标累计 300-500 字
- 包含 20 天的学习内容（500字）
- 点击汉字卡片听发音（Web Speech API）
- 每个字学会后获得 1 阳光
- 显示学习进度和今日已学数量

### 2. 古诗背诵 📜
- **一年级必背古诗 100 首**（含诗人、原文）
- 点击卡片听朗读
- 每首背诵后获得 5 阳光
- 包含静夜思、春晓、咏鹅、悯农等经典诗篇

### 3. 数学练习 🔢
- **10以内加减法** 和 **100以内加减法**
- **99乘法表** 练习
- **简单除法** 练习
- **两位数乘一位数** 进阶乘法
- **思维练习题**（应用题、规律题、逻辑题）
- 答对得 2 阳光，答错自动加入错题本

### 4. 拼音学习 🔤
- **声母 23 个**（已掌握）
- **单韵母 6 个**（已掌握）
- **复韵母 9 个**（⭐ 重点掌握）
  - ai ei ui ao ou iu ie üe er
- **鼻韵母 9 个**（前鼻音 + 后鼻音）
- 复韵母部分用红色高亮重点提示

### 5. 错题本 ❌
- 自动记录答错的题目
- 显示科目、内容、正确答案、日期
- 支持"已练习"和"删除"操作
- 错题数量实时显示在导航栏徽章上

### 6. 保卫基地 🏰
- **植物大战僵尸主题游戏**
- 5 项任务（汉字、古诗、数学、英语、拼音）
- 完成全部任务即可保住基地（血量 100%）
- 僵尸会随着未完成任务数增加而逼近
- 显示任务完成进度和基地血量条

### 7. 奖励中心 🎁
- 用学习赚的阳光兑换奖励：
  - 🍦 **30阳光** → 吃冰淇淋
  - 📺 **50阳光** → 看电视半小时
  - 🧸 **150阳光** → 买个小玩具
  - 🎢 **300阳光** → 去游乐场玩
- 阳光不足时显示灰色锁定状态

### 8. 打卡日历 📅
- 显示当前月日历
- 今日打卡获得 5 阳光
- 自动标记漏打卡日期
- 显示全勤天数和总结

### 9. 健身饮食 🏃
- 一年级运动建议：每天 60 分钟中等强度运动
- 8 种运动推荐（跳绳、摸高、游泳等）
- 长高食物推荐（牛奶、鸡蛋、鱼、豆腐等）
- 详细饮食原则和营养建议

### 10. 英语拓展 🌐
- **30 个简单日常英语词汇**
- 包含问候、家人、学校、动物、颜色等主题
- 点击听英文发音
- **10 道思维拓展题**（找不同、找规律、逻辑推理等）

### 11. 计划备忘录 📋
- 预设 12 项一年级准备事项
- 三大分类：🎒物品、📚学习、🌟生活
- 支持添加自定义待办
- 显示完成进度

## 技术特性

- **纯前端**：HTML + CSS + 原生 JavaScript，零依赖
- **数据持久化**：localStorage 存储所有学习数据
- **响应式设计**：支持电脑、平板、手机
- **语音朗读**：使用 Web Speech API（需要浏览器支持）
- **动画效果**：CSS3 动画，包括阳光掉落、植物摇摆、卡片浮动等
- **游戏化设计**：阳光收集系统、基地保卫战、奖励兑换

## 数据统计

- 📝 汉字：**500 个**（20天 * 25字）
- 📜 古诗：**100+ 首**经典一年级必背
- 🔤 拼音：**47 个**音节单元
- 🔢 数学题：每日自动生成约 **20+ 题**
- 🌐 英语：**30 个**日常词汇
- 🧩 思维题：**10 道**逻辑题

- **主色**：浅蓝色（#4FC3F7）+ 白色
- **辅色**：向日葵黄、豌豆绿、僵尸灰
- **字体**：卡通风格（Comic Sans MS）
- **主题**：植物大战僵尸游戏氛围

## 浏览器要求

- Chrome 80+
- Edge 80+
- Firefox 75+
- Safari 13+
- 移动端浏览器（建议横屏使用）

## 注意事项

1. **语音功能**：需要在用户交互（点击）后才会触发，避免浏览器自动播放拦截
2. **数据存储**：所有学习数据保存在浏览器 localStorage，清除浏览器数据会丢失记录
3. **emoji 显示**：在支持 emoji 的设备上会显示生动的表情图标
4. **最佳体验**：建议使用 1280px 以上屏幕的电脑或平板访问
